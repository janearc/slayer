# Preparing the large working view

A set with hundreds of recipes can spend significant time in the producer's
typed reader, before geometry staging starts. Run the initial typed read
and existing lightweight geometry path on the serial staging worker when
a packaged staging helper is available. If the lightweight path refuses
a valid draft, the same request continues to the shared staging helper.
Invalid YAML still reports its schema error. Opening queues no photograph.

A request owns an exact source snapshot and publishes data only after
the existing cancellation and current-document checks. Provisional edit
behavior and the standalone lightweight path without the helper remain
supported. Measure typed reads, request kickoff and helper launch
separately from window, staging and frame time.
