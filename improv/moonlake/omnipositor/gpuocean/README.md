# GPU ocean primitives

This package contains Metal primitives for unpolarized Fresnel reflection, reflected-sky direction, Gaussian slope probability, pinhole camera ray generation, projected sky lookup and periodic bilinear wave-field sampling. They form the building blocks of an experimental open-water renderer. Fresnel accepts a bounded batch of cosine/index pairs with indices from 1e-10 through 1e10 and returns float32 reflectances. The index restriction prevents overflow and underflow in the kernel's squared-index arithmetic. Rays use the ocean camera's orientation and return directions in bottom-up frame order. The CPU ocean uses float64, so numerical equivalence remains to be measured.

The host wave builder uses the CPU ocean's banded patches and position-locked random draws to prepare the three cascades. The ray helper prepares adjacent-pixel angles for bounded batches. An open-water ray-march primitive accepts those fields and returns hit distances, and separate kernels compute choppy surface slopes, reflected-sky directions and sea radiance. `Render` assembles those primitives in bounded batches using the CPU scene setup and host wave grids. The compositor can select this renderer explicitly with `--experimental-gpu-ocean`; it allocates and transfers between stages and has not been compared to the historical chain. No scene, benchmark or test has been run for this package.
