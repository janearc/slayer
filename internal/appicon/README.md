# Slayer's application icon

These are the supplied Miami quasar icons, copied unchanged from Miami's
`dist/` directory. They are rendered artwork, used here at the project
owner's request. Both originals are 1024 by 1024 PNGs.

The native survey viewer selects the variant for the system appearance.
The specimen book writes the same assets beside its HTML and selects its
favicon by the browser's colour scheme. Neither needs the Miami checkout
at build time or runtime.
