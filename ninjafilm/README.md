# ninjafilm

Photographic film stocks for Slayer scenes. A renderer supplies linear
light; ninjafilm develops it with the grain, spectral sensitivity, and
colour response of a chosen stock. Several renders taken during one shutter
opening can be combined into a frame with motion blur.

ninjafilm does not render geometry. You provide the scene, camera, and
renderer; it provides the film and the darkroom.
