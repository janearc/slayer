# New Horizons geometry

The three binary STL files are NASA's printable New Horizons model:
https://science.nasa.gov/3d-resources/new-horizons/
NASA describes the files as a printable model; they are illustration
geometry, not flight-grade blueprints. Source file SHA-256 hashes:

- body.stl: 25bf8ab489cf94b7b0ad0b60a14b11d473dae2477b8b242047d8ba870ab5dcc6
- antenna.stl: 422c44592b9b703a68604af02c0996811179567400c40336c3a0af8a064e3c24
- rtg.stl: d04671f1aa1aaa55716d4ef57436e190e87fb942b72fe5b80d8e61135e9f977a

The antenna STL spans 4.1335 print units. It is scaled to a 2.1 m
flight antenna diameter, as stated in NASA's spacecraft description:
https://science.nasa.gov/photojournal/new-horizons-at-pluto-artists-concept/

The same scale applies to all three parts. Original print orientations are
reassembled by eye; RTG location, dish elevation, colours and finish are
visual estimates. The STL body merges instruments and blanket into one mesh,
so its uniform gold look is not physically accurate. Some printer locating
holes and faceted surfaces remain. Three physical mesh parts contain 22,214
triangles; this count is not 22,214 separately modelled components.

NASA media guidelines apply to the supplied 3D resources:
https://www.nasa.gov/nasa-brand-center/images-and-media/
