# Silvery detailed pterosaur study

`study: detailed-silver` is an explicitly artistic alternate reflected
appearance for the detailed pterosaur, with a cool pale mottled hide, fibres,
beak and plain pale membranes. It preserves the detailed geometry and
authored phase/bank, and emits no light. The default detailed appearance is
unchanged. Like `detailed-plain`, this GPU-oriented study omits the membrane's
rest-space paint because the GPU path cannot currently render it on the posed
mesh; the hide remains mottled. This colour is not an evidence-based claim
about Hatzegopteryx. Lighting and visual readability require observation.
