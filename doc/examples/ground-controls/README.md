# Generated ground comparisons

Inputs for six CPU studies with Slayer ac67724c9, Azazel 229–234. The two
sea sets have identical seed and ocean/variation values, differing only in
ridge contrast (0 and 1). The land set changes ocean and variation as well.
Cloud coverage is explicitly zero so ground remains visible. These are
artistic parameters, not evidence of physical terrain or mountain geometry.
All six completed and were inspected. Changing ocean and variation together
visibly changed the land/sea balance; the matched ridge controls preserved
geography while adding pale branching marks. The marks read as artificial
colouring, and the land remains soft and mottled rather than convincing
topography. The images are studies, not investor-polished frames. Jobs contain
their original absolute paths; use fresh outputs if reproducing.
