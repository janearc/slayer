# Participating ocean water from submerged spot lamps

This is an explicit first slice of homogeneous clear-medium single scattering, implemented on CPU and Metal. It admits only named underwater spot lamps to a bounded camera-ray source integral. Existing direct spot and flood illumination on surfaces stays unchanged. The directionless flood is excluded from the scattering source; it is not a physical point emitter.

A material's `clear.extinction-per-metre` remains total extinction. Its optional `clear.scatter` block supplies a separate RGB scattering coefficient, phase parameter, fixed step count and maximum camera-path distance. Scattering may not exceed total extinction in any channel; the staged absorption is the nonnegative difference. Without the block, legacy extinction-only transport is bit-for-bit unchanged.

`world.ocean.in-scatter: spot-lamps` is a separate opt-in that allows the ocean boundary's participating medium to sample authored `film.Spot` sources. Each selected spot must be below the mean water plane and point downward; flood and other non-spot lights remain direct-only. Camera integration is clipped by the existing finite first-hit segment and explicit distance/step limits. Spot-to-sample source paths use existing opaque visibility. Neither backend refracts or attenuates lamp paths through a water boundary, scatters sky/flood illumination, or models wave-normal scattering. It is refused for other clear boundaries, unsupported scene volumes/fields, unsupported emitters, non-ocean clear media, and unsupported GPU draws. Metal supports only fixed camera stacks with a closed shutter; moving-camera stacks, moving shutters and optical state in composite passes remain refused because the current APIs cannot transport a time-varying stack or carry clear-medium state through composite rendering.

The scene's coefficient source must be labeled measured or synthetic; this code invents none. Metal's opt-in ABI is separate from the ordinary shader: the legacy no-optics source remains hash-locked to its baseline, and default GPU jobs continue through the original path.
