# Space instruments for heard.

Hubble, Spitzer and Webb need to remain recognizable when a shot moves
behind them. These are procedural scenery models. Their reference
apertures and Webb's existing optical layout remain sourced; new trim,
hardware dimensions and poses are picked in spacecraft-choices.yaml.

Hubble now has an open aperture door, paired communication dishes on
booms, raised equipment-bay doors, housing bands and secondary supports.
The scene retains the existing simplified tube and solar wings. It does
not model servicing-era changes, actuators or optical performance.

Spitzer receives equipment-bay relief, thermal collars and secondary
supports. Its existing single rectangular solar shield is still a proxy:
the actual panel assembly is wedge-shaped and tilted. That silhouette
needs a separate correction, not a claim that extra trim has fixed it.

Webb retains the existing five-layer shield, segmented gold primary and
secondary assembly. A braced rear frame surrounds the instrument module,
with an authored radiator surface. The four instruments remain enclosed
in one proxy module; this is not internal engineering geometry.

## Visual references

NASA's [Hubble cutaway](https://science.nasa.gov/asset/hubble/hubbles-instruments-including-control-and-support-systems-cutaway/)
identifies the aperture door, communication antennas and support systems.
It guides which features to show, not the authored dimensions.

The mission's [Spitzer spacecraft](https://www.spitzer.caltech.edu/mission/the-spacecraft)
and [solar panel assembly](https://www.spitzer.caltech.edu/mission/the-solar-panel-assembly)
describe the warm octagonal bus and the shielding panel arrangement.
The [cold assembly](https://www.spitzer.caltech.edu/mission/the-cryogenic-telescope-assembly)
separates telescope, instrument chamber, cryostat and outer shell.

NASA's [Webb backplane](https://science.nasa.gov/mission/webb/webbs-backplane/)
places the instrument module behind the primary and describes the
supporting structure. Member layout and radiator size here are artistic
choices.
