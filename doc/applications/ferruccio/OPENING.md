# Open inside the world

The opening shows the supplied native Larson and two-metre scale figure
before requesting any render. A real pre-rendered view is bundled with its
exact source, image and producer fingerprints. The current document must
match the source fingerprint; native picking is built from that same source.
A changed or corrupt starting asset is refused rather than shown as current.

The normal Play window starts ready for selection, movement and examination.
It does not need a queue acknowledgement before showing the starting world.
Source and construction remain available behind their existing disclosures.

Each settled edit makes one finite draw. A request is never silently
retried after an uncertain queue submission. Catalogue plans are refused
because they require their own producer.
