# Open a scene

Play opens on the native Larson example with its working view. A path supplied
on the command line or chosen in **Open…** selects that source instead.
Opening a source or choosing another example does not submit a render.
Large scenes stage in a background helper. See [Edit a scene](FIRST-PLAY.md).

A command-line launch can supply `--starter DIR` with `source.yaml`,
`preview.png` and `receipt.json`. Ferruccio checks the source and picture against the receipt before
accepting that picture for the open document. Choose **Solid**, **Edges**, or
**Wire** to select objects in the working view. The standard app build opens
the working view without a prepared starter.
