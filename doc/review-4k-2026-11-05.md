# Committed 4K review measurement

Measured 2026-11-05 on Apple M3 Max, two Go workers, one render at a time.
Both scenes used one clean executable from commit
f1ca8ef26e5eed25949a14d0d827f17aa05adda4.

5000 coast redwoods, terrain, prescribed mist and an optical observatory;
3840x2160, sixteen samples per pixel. Only the renderer selection changed.

- Software primary (gpu), whole command: 553.2302015 seconds.
- Native primary (gpu-native), whole command: 59.749946417 seconds.

Native issued 132710400 queries, received 121306547 candidates, refined
115228503 and used 6078044 software fallbacks. Those fallbacks are included
in its time. Native dispatch GPU time was 50.451405130 seconds.

135543/8294400 PNG pixels exceeded one OKLab JND: 1.63415075 percent, within
the existing two-percent budget. Worst: 8.66235649 JND at (550,1199).
Alpha was identical; all raw RGB was finite. PFM has no depth or coverage.

Both PNGs were visually inspected. The committed animation benchmark passed
in 619.333 seconds; its README gives the commands. Artifacts and hashes are
in out/review-4k/measurement.json. This still test establishes no motion bound.

The older 64.057-second working-tree experiment remains historical and
predates the shared-range fix. These are the measured committed results.
