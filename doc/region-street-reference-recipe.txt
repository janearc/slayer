Reference crops cut from the existing 2048 by 1820 street PNG. These are not
newly rendered regions. The original was recorded at four rays per side,
sixteen samples per pixel, on the GPU, with street-2k.yaml.
The original executable revision and exact GPU mode have not been established.

Each rectangle is left, top, width, height in original image pixels:
water: 1020, 1260, 320, 300
wall: 75, 250, 320, 350
haze: 570, 160, 300, 350
lamps: 1300, 0, 350, 260
end: 850, 700, 350, 350

Each cut used `sips --cropOffset TOP LEFT -c HEIGHT WIDTH SOURCE --out OUTPUT`
with the numbers above and the existing PNG as SOURCE. No resampling was
requested for these cuts.

The water contains isolated bright points in a yellow reflection. The wall
has red speckle with hard slanted boundaries. The haze has yellow specks in
columns. The cool lamp halo is grainy. The end of the street is blown out.
These are candidate test areas, not evidence of a corrected image or of
independently rendered region equality.
